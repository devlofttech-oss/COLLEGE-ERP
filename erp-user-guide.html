Login & Authentication

🔐
Signing In
Session cookie auth — no tokens stored in browser
  1. 1Open the ERP URL in your browser and you will land on the Login page.
  2. 2Enter your email address and password assigned by your administrator.
  3. 3Click Sign In. The system authenticates with Firebase and sets an HTTP-only session cookie — you will never see a raw token.
  4. 4You are redirected to the Dashboard. The sidebar shows only the modules enabled for your institution and allowed by your role.

Forgot Password

  1. 1Click Forgot password? on the login page.
  2. 2Enter your email address and click Send reset link.
  3. 3Check your inbox for a Firebase password-reset email. The system does not reveal whether the email exists.

Signing Out

Click your avatar/name in the top-right corner and choose Sign out. Your session cookie is cleared immediately.

⚠️
Known gap: A "Sign out of all devices" button exists in the backend but has no UI yet. If you suspect a compromised session, contact your administrator to reset your Firebase credentials.

02 — Students

🎓
Student Management
Complete student lifecycle — enroll, track, promote, export
admin principal teacher (view)

Enrolling a New Student

  1. 1Go to Students in the sidebar.
  2. 2Click Add Student (top-right). A form slides in.
  3. 3Fill in Admission details (admission number, date, academic year), Student info (name, gender, DOB), Academic Placement (course, class, section), and Parents & Guardian info.
  4. 4Click Save. The student appears in the list immediately.

Searching & Filtering

🔍Search by name, admission no., or roll no.
📚Filter by Academic Year, Course, Class, Section
⚡Filter by Status (active / alumni / transferred)
📦Toggle "Include Archived" to see deactivated records

Viewing a Student Profile

Click any row in the table to open the student drawer on the right. It has tabs:

  • Profile — personal, academic, and guardian details
  • Documents — photo, Aadhar, TC, certificates. You can upload, verify, or reject each doc.
  • Placement History — record of promotions and transfers
  • ID Card — generate and download a PDF ID card

Promoting / Transferring a Student

  1. 1Open the student drawer and click Move / Promote in the footer.
  2. 2Choose action: Promote (move to next class/year) or Transfer (to another institution).
  3. 3Select the target Academic Year, Class, and Section. Add a reason. Click Save.

Bulk Import

  1. 1Click Import (top-right).
  2. 2Paste or upload a JSON/CSV array of student records.
  3. 3Click Import. Invalid rows are skipped; valid ones are created.

Exporting

Click Export — a CSV file downloads with the current filter applied.

ℹ️
Archiving a student hides them from normal lists but does not delete the record. Use Restore from the drawer footer to reactivate.

03 — Fees

💰
Fee Management
Heads → Structures → Assignments → Collection → Receipts
admin accountant principal (view)

Setup Flow (first time)

  1. 1Create Fee Heads — e.g. "Tuition Fee", "Lab Fee", "Transport Fee". Go to Fees → Heads tab → Add Head.
  2. 2Create Fee Structures — bundle heads with amounts for a course/class. Go to Fees → Structures tab → Add Structure.
  3. 3Assign to Students — link a structure to individual students or a whole batch. Fees → Assignments → Assign.

Collecting a Fee Payment

  1. 1Go to Fees → Collect tab. Search for the student.
  2. 2The due items for that student appear. Select the items to pay.
  3. 3Enter the amount received, payment mode (cash / UPI / cheque / online), and any remarks.
  4. 4Click Collect. A receipt is generated automatically.

Printing a Receipt

Go to Fees → Payments, find the payment, click the PDF icon. The receipt opens in a new tab as a printable PDF.

Dues Report

Fees → Dues tab. Filter by academic year, course, or class to see outstanding dues. You can also send payment reminders (SMS/email integration required in Settings).

⚠️
Online payment order creation (Pay / Order) requires Razorpay or similar configured in Settings → Integrations. Without that, only manual collection works.

05 — Academics

📚
Academics
Academic years, courses, classes, sections, subjects, teacher allocations
admin principal

Initial Academic Setup Order

  1. 1Academic Year — Create the year (e.g. "2025–26"). Mark it as Current.
  2. 2Courses — Add courses (e.g. "B.Com", "BCA"). Link to an academic year.
  3. 3Classes — Add class levels per course (e.g. "First Year B.Com").
  4. 4Sections — Divide each class into sections (A, B, C).
  5. 5Subjects — Add subjects per class. Assign a teacher to each subject.
  6. 6Teacher Allocations — Formally allocate teachers to classes/sections if needed beyond subject assignment.
ℹ️
Only one Academic Year can be "current" at a time. Setting a new current year automatically unsets the previous one. The current year is used as the default filter in Students, Fees, and Attendance.

08 — Examinations

📝
Examinations
Exams, schedules, marks entry and verification
admin teacher (marks entry) principal (verify)

Creating an Exam

  1. 1Go to Examinations. Click Add Exam. Enter name (e.g. "Mid-Term 2025"), type, academic year, max marks.
  2. 2Click Save.

Adding a Schedule

  1. 1Under Schedules tab, click Add Schedule.
  2. 2Select the Exam, Subject, Class, Date, and Time. Click Save.

Entering Marks

  1. 1Go to the Marks tab. Select Exam, Subject, and Class.
  2. 2Enter marks for each student in the table. Click Save Marks.
  3. 3Marks are in draft state until verified.

Verifying Marks

An admin or principal can Verify a batch of marks to lock them. Use Unlock to allow corrections after verification.

09 — Results

🏆
Results
Grade settings, result processing, report cards, publishing
admin principal teacher (view own) student (view own)

Processing Results

  1. 1Configure Grade Settings first — define grade bands (e.g. A: 90–100, B: 75–89). Go to Results → Grade Settings.
  2. 2Click Process Results. Select the Exam and Class. The system calculates totals, percentages, grades, and pass/fail based on verified marks.
  3. 3Review the generated results list.
  4. 4Click Publish to make results visible to students/parents via My Portal. Or Lock to prevent further edits.

Report Cards

Go to Results → Report Card. Select an Exam and Student. View the card or download a PDF version.

10 — Notices & Communication

📢
Notices & Communication
Broadcast notices, manage message templates
admin principal teacher (view) parent (via portal) student (via portal)

Creating and Sending a Notice

  1. 1Go to Notices. Click New Notice.
  2. 2Enter the title, body, audience (all / class / role), and priority.
  3. 3Click Save as Draft to keep it private, or Send to push it to the portal and any configured SMS/email channel.

Under the Templates tab, create reusable message templates for fee reminders, attendance alerts, or exam notifications. Templates use placeholder variables like {{studentName}}, {{amount}}.

11 — Admissions

🚪
Admissions
Enquiries → Applications → Approval → Convert to Student
admissions-officer admin principal (approve)

Admission Pipeline

  1. 1Enquiry — A prospective student walks in. Click New Enquiry, fill in contact and course interest details.
  2. 2Follow-ups — Log follow-up calls/visits on the enquiry record. Each follow-up has a date, notes, and next action.
  3. 3Move to Application — When the student is serious, click To Application to upgrade the record.
  4. 4Approve / Reject — Principal or admin reviews and clicks Approve or Reject.
  5. 5Convert to Student — On approval, click Convert to Student. A full student record is automatically created from the admission data.

15 — Users & Roles

🛡️
Users & Roles
Manage ERP users, assign roles, customise permissions
admin only

Creating a User

  1. 1Go to Users & Roles → Users tab. Click Add User.
  2. 2Enter email, display name, and select a Role. For parent accounts, select students to link in the Linked Students field.
  3. 3Click Save. A Firebase account is created and the user can log in with a password reset link.

Customising Role Permissions

  1. 1Go to the Roles tab. Select a role (e.g. "teacher") from the left panel.
  2. 2The right panel shows all permission groups (students, fees, attendance…). Toggle individual permissions on/off.
  3. 3Click Save Permissions. Changes take effect on next login.
  4. 4Use Reset to Default to restore a role's factory permissions.
ℹ️
The super-admin role cannot be customised — it always has full access and is reserved for Devloft platform administrators.

17 — Files (Storage)

📁
Files
Upload, download, and manage documents in cloud storage (R2)
admin principal

Uploading a File

  1. 1Go to Files. Select a Folder (e.g. student-photos, documents, receipts). Folder policy shows allowed types and max size.
  2. 2Enter the Owner ID (usually a student or staff ID), select the file, set the filename.
  3. 3Click Generate Upload URL — the backend signs a temporary upload URL.
  4. 4Click Upload File — the file uploads directly to Cloudflare R2.
  5. 5The Upload Response panel shows the storage key. Click Use Key to pre-fill the download/delete tools.

Downloading / Resolving a File

In the Download sub-form, paste the storage key and click Generate. A signed download URL is created. Click Open to view the file or Copy URL to share it.

Deleting a File

In the Delete Object sub-form, paste the storage key and click Delete. This is permanent and irreversible.

🔴
The Files module is an internal admin tool. End users (students, parents, teachers) never interact with it directly — they access files through their respective modules (student documents, receipts, etc.).

⚠️ Known Gaps (Non-Critical)
GAP
Logout Everywhere — POST /auth/logout-everywhere exists in the backend and revokes all Firebase sessions, but there is no button in the UI that calls it. If an account is compromised, the only recourse currently is to reset the Firebase password.
Fix: Add "Sign out of all devices" button to the user account/profile menu.
GAP
Academics — classes response key fallback — The frontend reads data.classes || data.classs for the classes list. The data.classs fallback suggests there was uncertainty about what the backend returns. Should be confirmed and the fallback removed.
Fix: Verify crudController list response key for entity="class" and remove the redundant fallback.
GAP
Fee Structure / Head — no restore — Archive is wired for fee heads and structures but there is no restore route on the backend and no restore button in the UI. Archived heads/structures cannot be recovered without direct DB access.
Fix: Add POST /fees/heads/:id/restore and POST /fees/structures/:id/restore routes.
GAP
Files DELETE uses query param — DELETE /files?key=... passes the key as a query param rather than in the request body. This works but is non-standard (RFC advises against request bodies on DELETE, but query params are fine). No functional issue.
